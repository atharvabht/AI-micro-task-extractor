# AI Micro Task Extractor – Chrome Extension

## 📌 Overview

AI Micro Task Extractor is a Chrome Extension that leverages Artificial Intelligence to analyze web page content and automatically extract actionable micro-tasks. Instead of manually reading long articles, documentation, blogs, or tutorials to identify important steps, the extension generates a structured checklist of tasks within seconds.

The goal is to improve productivity by converting unstructured information into clear, actionable items.

---

## 🚀 Features

* 🤖 AI-powered task extraction from web pages
* 📄 Converts lengthy content into concise to-do lists
* ⚡ One-click task generation
* 🎯 Identifies actionable instructions and key steps
* 📋 Copy extracted tasks to the clipboard
* 💻 Simple and intuitive Chrome Extension interface
* 🔒 Privacy-focused (only processes content when the user requests extraction)

## ⚙️ Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/ai-micro-task-extractor.git
```

2. Open **Google Chrome**.

3. Navigate to:

```
chrome://extensions
```

4. Enable **Developer Mode**.

5. Click **Load unpacked**.

6. Select the project folder.

7. The extension is now installed and ready to use.

---

## 📖 How It Works

1. Open any webpage containing text.
2. Click the **AI Micro Task Extractor** extension.
3. The extension captures the visible page content.
4. The AI analyzes the text and identifies actionable tasks.
5. A clean checklist is displayed inside the extension popup.
6. Copy or save the extracted tasks for future use.
